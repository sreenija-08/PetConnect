Verification Routing Guide:
  • < Auto-Reject Threshold: Status set to AUTO_REJECTED. Owner receives email with failure reasons and resubmission guidance. Admin direct approval is blocked.
  • Between Auto-Reject and Low-Risk: Status set to MANUAL_REVIEW. Administrator must manually inspect certificate discrepancies.
  • ≥ Low-Risk Threshold: Status set to PENDING (Low Risk). Eligible for expedited administrator approval.
  • Hard-Fail Rules: Wrong document type, inverted issue/expiry dates, or conflicting registration numbers trigger instant auto-rejection regardless of score.
